🩸 Life Saver – Blood Donor Application

Life Saver is a blood donation management application that connects **patients who need blood with available donors** based on blood group and location.

Features

* User registration and login
* Donor registration and profile management
* Patient blood request
* Search donors by blood group and location
* Donor availability management
* Admin management of users, donors, and blood requests

 👥 Roles

🩸 Donor

* Register and login
* Manage profile
* Add blood group and location
* Update availability
* Respond to blood requests

🏥 Patient

* Register and login
* Create blood requests
* Specify required blood group and location
* View available donors
* Track blood request status

🛡️ Admin

* Admin login
* Manage users and donors
* View and manage blood requests
* Verify or remove donor records
* Monitor application activities

🛠️ Technologies

* Backend:Java, Spring Boot, Spring MVC, Spring Data JPA
* Frontend:Angular, HTML, CSS, JavaScript
* Database:MySQL
* Tools:Git, GitHub, Postman, Maven

To provide a simple platform where patients can request blood and quickly connect with suitable donors.
